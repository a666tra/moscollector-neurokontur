## 📊 Честная валидация и ключевые показатели (No Data Leakage)

Модель валидирована по строгому протоколу **3-Way Out-of-Time split** (Train: 01–14 янв, Val: 15–21 янв, Held-out Test: 22–28 янв) без заглядывания в будущее. На отложенном тесте зафиксировано 174 события критической аномалии / предотказного состояния из 10 712 каналов (экстремальный дисбаланс классов 1.62%). В датасете отсутствуют внешние журналы ремонтов CMMS, поэтому целевая переменная сформирована строго алгоритмически по физическим маркерам будущего окна телеметрии (загазованность $\ge 5.0\%$, $t \ge 45^\circ\text{C}$ или $\le -10^\circ\text{C}$, сброс часов в 1970г, обрыв связи/питания), исключая data leakage.

## 🏛️ Ключевой функционал Ситуационного Центра ОДС

1. **Интерактивная карта коллекторной сети (ГИС):**
   - 95 диспетчерских узлов и 825 км подземных тоннелей Москвы.
   - Детализация до конкретного пикета (ПК1–ПК120).
   - Защита сведений о КИИ по 149-ФЗ: параметрическая инженерная топологическая модель.
2. **Интеллектуальный фильтр ложных тревог (Human-in-the-Loop по ГОСТ Р 53195):**
   - Детектирование аппаратного дребезга герконов дверей/люков и вибрационных наводок.
   - Ролевая аутентификация диспетчера (`ДИСП-XXXX`) из официального реестра ОДС.
   - Неизменяемый криптографический реестр аудита SHA-256 с возможностью сквозной проверки целостности цепочки.
3. **Предиктивный мониторинг 10 712 каналов & Live Sandbox:**
   - Оценка риска деградации сенсоров на 24–72 часа.
   - Интерактивная песочница: ручное изменение значений телеметрии и онлайн-пересчет риска за 2.38 мс.
4. **Управление нарядами ТО и ППР по регламенту Р ТЭК:**
   - Автоматическая генерация наряд-заказов с привязкой к пикетам (ПК1–120).
   - Распределение по профильным службам (КИПиА, Электротехническая, Вентиляция) и автоматический расчет ЗИП.
   - Персистентное хранилище нарядов (`backend/data/tickets_db.json`).
5. **Настройки системы (Раздел 18.3 ТЗ):**
   - Модальное окно конфигурации: регулировка порога отсечки $\tau$ (0.10–0.90), окна дребезга, стоимости выезда и ТО.
6. **ML-Метрики и Валидация:**
   - Прозрачное сравнение 4 моделей (Zero-Rule, Logistic Regression, Random Forest, Champion LightGBM).
   - Вклад признаков (Feature Importance) и бенчмарк быстродействия.

## 🔒 Безопасность и соответствие законодательству РФ

- **149-ФЗ «Об информации, информационных технологиях и о защите информации»:** Интеграция со SCADA в режиме Read-only; безопасная параметрическая топологическая модель объектов КИИ.
- **152-ФЗ «О персональных данных»:** Сервис работает без сбора ПДн (только обезличенные служебные табельные номера).
- **ГОСТ Р 53195:** Человек в контуре управления (Human-in-the-Loop) и криптографический реестр аудита SHA-256.
- **Импортозамещение:** 100% открытые технологии, автономная работа в закрытом контуре без внешних облачных API.
